# Plantões Medicina Fetal - São Caetano

Formulário web para registro de plantões de médicos.

## Como usar

1. Abra `index.html` no navegador
2. Digite seu CRM (nome será preenchido automaticamente)
3. Selecione data e turno
4. Clique em "Adicionar Plantão"
5. Baixe o CSV para atualizar sua planilha Excel

## Médicos Validados

Total de 36 médicos registrados no banco de dados.
